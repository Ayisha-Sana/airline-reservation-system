# ✈️ Airline Reservation System

A command-line airline reservation system built using Python and MySQL.

## Features

- Add flights
- View all flights
- Search flights by origin and destination
- Check seat availability
- Book tickets
- View bookings
- Cancel tickets
- Print ticket details

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Database

The project uses MySQL with two main tables:

- `flights`
- `bookings`

The `airline_db.sql` file contains the database structure.
